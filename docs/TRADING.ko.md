# 트레이딩 데스크 — TradingAgents × 바이낸스 선물

Munder Difflin 안에서 [TradingAgents](https://github.com/TauricResearch/TradingAgents)의 멀티 에이전트
트레이딩 알고리즘을 **바이낸스 USDⓈ-M 무기한 선물(BTCUSDT, ETHUSDT)** 에 적용한 기능입니다.
모든 에이전트 보고서와 화면은 한국어로 나옵니다.

> **연구용 도구이며 투자 조언이 아닙니다.** LLM 에이전트와 규칙 기반 스캘퍼는 틀릴 수 있고,
> 레버리지 선물은 예상보다 큰 손실이 날 수 있습니다. 반드시 **모의투자 → 바이낸스 데모 → 소액 실거래**
> 순서로 검증하세요.

> **처음 설치하는 방법과 바이낸스 API 자동매매 설정은 [`TRADING-SETUP.ko.md`](./TRADING-SETUP.ko.md)** 에 단계별로 있습니다.

## 여는 법

1. 설정 → 일반 → 언어에서 **한국어**를 고릅니다 (앱은 기본 영어로 시작합니다).
2. 오케스트레이터(Michael) 카드를 선택해 **커맨드 센터**를 엽니다.
3. 탭 줄 끝의 **트레이딩** 탭을 누릅니다.

트레이딩 탭은 `개요 · 에이전트 · 거래내역 · 로그 · 설정` 다섯 화면으로 되어 있습니다.

## 두 가지 모드

### 1. 에이전트 알고리즘 모드 (TradingAgents)

TradingAgents의 그래프를 그대로 따릅니다. 종목마다 설정한 간격(기본 60분)으로 실행됩니다.

```
분석가 팀 (병렬)                     리서치 팀                    트레이더
 ├ 기술적 분석가     ┐               강세 연구원 ⇄ 약세 연구원       │
 ├ 파생상품 분석가   ├──────────▶   (N 라운드)      ─▶ 리서치 매니저 ─▶ 트레이더
 ├ 뉴스 분석가       │                                              │
 └ 심리 분석가       ┘                                              ▼
                                리스크 관리 팀: 공격적 → 보수적 → 중립 (N 라운드)
                                              │
                                              ▼
                        포트폴리오 매니저 (최종 등급 + 주문용 JSON)
                                              │
                                              ▼
                     리스크 엔진(코드) ─▶ 주문 실행 (모의 / 데모 / 실거래)
```

| 역할 | 보는 데이터 |
|---|---|
| 기술적 분석가 | 15분·1시간·4시간·일봉의 EMA/SMA, MACD, RSI, 볼린저(밴드폭 백분위), ATR, VWMA, 스윙 지지/저항, 최근 캔들 |
| 파생상품 분석가 | 펀딩비(현재·평균·연환산), 미결제약정 4h/24h 변화, 전체·상위 트레이더 롱숏 비율, 테이커 매수/매도 비율, 베이시스, 호가 불균형 |
| 뉴스 분석가 | CoinDesk·Cointelegraph·Decrypt·Bitcoin Magazine RSS (최근 48시간, 코인 관련 / 거시 분리) |
| 심리 분석가 | 공포·탐욕 지수(alternative.me), 군중 포지셔닝, 헤드라인 논조 |

- TradingAgents의 **펀더멘털 분석가**는 무기한 선물에 맞게 **파생상품 분석가**로 바꿨습니다.
- 에이전트는 도구를 호출하지 않습니다. 모든 수치는 앱이 바이낸스에서 직접 계산해 "검증된 시세 스냅샷"으로 넘깁니다.
  그래서 API 키 없이 **Claude 구독(숨은 세션)** 으로도 돌릴 수 있습니다.
- 등급 척도는 TradingAgents와 같습니다: `Buy / Overweight / Hold / Underweight / Sell`
  (선물에서는 Buy=강한 롱, Overweight=작은 롱, Hold=관망, Underweight=작은 숏, Sell=강한 숏).
- 포트폴리오 매니저는 마지막에 `action, entryType, entryPrice, stopLoss, takeProfit, leverage, riskPct, confidence` JSON을 붙이고,
  리스크 엔진이 이를 검증합니다. JSON이 없으면 한 번 더 요청하고, 그래도 없으면 등급만 보고 **주문 없이** 처리합니다.
- 종료된 거래는 회고(reflection)로 교훈을 남기고, 다음 결정 때 포트폴리오 매니저가 읽습니다.
- 실행이 끝나면 전체 보고서가 마크다운 파일로 저장됩니다 (`에이전트` 화면 → 보고서 폴더 열기).
- 데스크가 **정지** 상태에서 "지금 분석"을 누르면 **분석만** 하고 주문은 내지 않습니다.

### 2. 스캘핑 모드

LLM 응답은 수 초~수십 초가 걸려 1분봉 진입 판단에 쓸 수 없으므로, 틱 판단은 규칙 기반으로 하고
에이전트는 **방향 필터**만 맡습니다.

- 매 `확인 주기`(기본 5초)마다 진입 시간대(기본 1분봉)와 추세 시간대(기본 5분봉), 호가 20단계를 읽어
  롱/숏 점수(0~100)를 계산합니다.
  - 상위 추세 정렬 25 · EMA9/21 모멘텀 20 · 눌림목 회복 또는 스퀴즈 돌파 20 · RSI(7) 10(과열 감점) ·
    테이커 흐름 + 호가 불균형 15 · 거래량 동반 10
- 한쪽 점수가 `최소 진입 점수`(기본 65) 이상이고 반대쪽보다 10점 이상 높을 때만 진입합니다.
- ATR·스프레드 필터, 청산 후 쿨다운, 시간당 최대 진입 수를 지킵니다.
- 손절 = 진입가 ∓ 1.2×ATR, 익절 = 진입가 ± 1.8×ATR (설정 가능). +1R에 도달하면 손절을 본전(+수수료)으로 옮기고,
  `최대 보유 시간`이 지나거나 강한 반대 신호가 나오면 청산합니다.
- **방향 필터 데스크**: 15분마다 TradingAgents의 분석가·강세/약세 연구원·리스크 관점을 한 번의 호출로 압축해
  `롱만 / 숏만 / 양방향 / 진입 금지`를 정합니다. 필터가 30분 이상 갱신되지 않으면 양방향으로 돌아갑니다.

## 실행 환경

| 환경 | 주문 | 필요한 것 |
|---|---|---|
| 모의투자 (기본) | 내 컴퓨터에서 시뮬레이션 (수수료·슬리피지·펀딩비·손절/익절·격리 청산 반영) | 없음 |
| 바이낸스 데모 | `demo-fapi.binance.com` 에 실제 주문 | demo.binance.com 에서 만든 데모 API 키 |
| 실거래 | `fapi.binance.com` 에 실제 자금으로 주문 | 실거래 API 키 + 설정의 위험 고지 동의 |

- 시세 분석은 항상 실거래 공개 시세를 씁니다.
- 손절·익절은 바이낸스 **Algo Order API**(`POST /fapi/v1/algoOrder`, `STOP_MARKET` / `TAKE_PROFIT_MARKET`, reduce-only,
  마크가격 기준)로 겁니다. 2025년 12월 이후 `/fapi/v1/order`로는 조건부 주문이 거부(-4120)되기 때문입니다.
- **손절 주문이 실패하면 즉시 포지션을 청산**합니다. 보호 없는 포지션은 두지 않습니다.
- 헤지 모드 계정이면 `positionSide`를 지정해 주문합니다.
- 실거래 API 키는 **선물 거래만 허용, 출금 비활성화, IP 허용 목록** 설정을 권장합니다.
- 키는 운영체제 보안 저장소(Electron safeStorage)로 암호화되어 저장되고 화면에 다시 표시되지 않습니다.

## 자동매매 (설정 → 자동매매)

| 옵션 | 기본값 | 내용 |
|---|---|---|
| 앱을 열면 데스크 자동 시작 | 꺼짐 | 앱 실행 약 8초 뒤 저장된 모드·환경·종목으로 시작 |
| 거래 중 컴퓨터 잠자기 방지 | 켜짐 | 데스크가 도는 동안 Electron powerSaveBlocker로 앱 일시 중단 방지 |
| 데스크톱 알림 | 켜짐 | 진입·청산·일일 한도 중단·오류 (오류는 1분에 한 번까지) |
| 로그인하면 앱 실행 | OS 설정 | 즉시 적용, 자동 시작과 함께 쓰면 재부팅 후 자동 재개 |

실거래를 시작할 때마다 바이낸스 `GET /sapi/v1/account/apiRestrictions`로 키 권한을 읽어,
**출금 권한이 켜져 있거나 선물 권한이 없으면 시작을 거부**합니다. IP 제한이 없으면 경고만 남깁니다.

## 리스크 엔진 (코드가 강제)

LLM이 무엇을 말하든 아래 규칙은 코드에서 강제됩니다.

- 손절가 없는 진입 거부, 손절이 잘못된 방향이면 거부, 현재가가 이미 손절가를 넘었으면 거부
- 포지션 크기 = (자본 × 거래당 최대 손실%) ÷ (손절 거리 + 왕복 수수료 + 슬리피지) — 모델이 말한 수량은 쓰지 않음
- 레버리지 상한, 그리고 **격리 청산가가 손절가보다 충분히 멀도록** 레버리지 자동 하향
- 자본 대비 최대 명목가, 가용 증거금, 거래소 최소 수량/최소 명목가
- 최소 손익비(기본 1.5:1), 최소 확신도(기본 0.55)
- **일일 손실 한도**(기본 -4%)나 **연속 손실**(기본 4회)에 닿으면 그날은 신규 진입 중단 (기존 포지션 관리는 계속).
  하루 기준은 UTC이며, 앱을 다시 켜도 카운터가 유지됩니다.

| 제공자 | 설명 |
|---|---|

| OpenAI 호환 서버 | Ollama, LM Studio, vLLM, OpenRouter 등 `/v1/chat/completions` |

분석가·연구원·토론자·트레이더는 빠른 모델, 리서치 매니저와 포트폴리오 매니저는 깊은 모델을 씁니다
(TradingAgents의 quick/deep 구분과 같음). 토론 1라운드 기준 한 번의 파이프라인은 LLM 호출 약 13회입니다.

## 알아둘 점

- 데스크를 **정지해도 열린 포지션은 그대로** 남습니다. 데모/실거래는 거래소에 걸린 손절·익절이 유지되지만,
  모의투자 포지션은 다시 시작할 때까지 손절·익절이 감시되지 않습니다.
- 앱이 꺼져 있으면 아무것도 실행되지 않습니다 (Munder Difflin의 "로그인 시 열기"·"잠자기 방지" 설정을 참고하세요).
- 바이낸스 선물 API는 일부 지역(IP)에서 막혀 있습니다 (HTTP 451).
- 입금·출금이 있으면 일일 손익 계산(자본 변화 기준)이 왜곡될 수 있습니다.
